# Technical SEO audit, 2026-10-27

Scope: both builds (dicta.uz, dicta.live). Checked by parsing every built HTML file.

## Findings
- Titles unique on every page in both builds; descriptions unique and present everywhere except the `/offer` redirect stub (fine, it redirects).
- Canonical, hreflang (locales plus x-default), og/twitter, theme-color and html lang/dir are all correct. 404 is noindex without canonical, by design.
- Home description was the hero subline; the title was the tagline. Neither targeted the three pillars.
- `public/robots.txt` hardcoded `https://dicta.uz/sitemap-index.xml`, so dicta.live advertised the wrong sitemap.
- Organization JSON-LD hardcoded dicta.uz and appeared only on the uz-style home; no WebSite entity; SoftwareApplication offer was a fake price of 0.
- FAQPage JSON-LD (`faqJsonLd`) is valid: every JSON-LD block in both builds parses and has the expected shape.
- llms.txt had no feature description.
- Fonts were not preloaded (Inter and Literata are self-hosted woff2 via fontsource, already `font-display: swap`).
- Images already go through astro:assets (webp, srcset, lazy; the hero is eager with fetchpriority high; dark variants lazy). No change needed.
- GA4 script is already `async`; the inline config is tiny. No change needed.
- Not fixed (outside owned files): `/delete-account` and `/privacy` descriptions are 230-250 chars (truncated in SERPs); the 404 page has 3 h1 elements.
- Instagram sameAs skipped: no Instagram URL is referenced anywhere in the repo.

## Fixed
- Home title and description per locale (uz/ru/en/ar), new module `src/i18n/pages/home-meta.ts` (ui.ts untouched). HomePage.astro reads from it.
- Organization and WebSite JSON-LD moved to Layout, emitted on each locale home, using `SITE.url` and the logo.
- SoftwareApplication offers now come from the live catalog (one Offer per plan, UZS), falling back to the free offer when the catalog is unavailable.
- `robots.txt` is now generated per site (`src/pages/robots.txt.ts`); the static file is removed.
- Preload of the first-paint Inter and Literata woff2 subsets (cyrillic for ru, latin for uz/en, none for ar).
- Yandex Metrica: tag.js counter injected only when `PUBLIC_YANDEX_METRICA_ID` is set (digits only), webvisor and clickmap on, skipped on noindex pages. `track()` also calls `ym(id,'reachGoal',event,params)`.
- RSS alternate link `/blog/rss.xml` in the head (the route comes from the blog agent).
- llms.txt: product description, all features from the brief, sitemap link.

## Bundle size (uz build, dist)
- JS: 2,754 B before, 2,810 B after (analytics ym call). CSS: 41,151 B before, 41,172 B after. The page weight is dominated by images and woff2 files, unchanged.
