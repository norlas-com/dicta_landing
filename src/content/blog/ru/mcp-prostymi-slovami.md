**Коротко:** MCP (Model Context Protocol) — это общий «разъём», с помощью которого AI-ассистенты подключаются к другим приложениям и данным единым стандартным способом. Вместо того чтобы делать отдельное подключение каждого ассистента к каждому приложению, все говорят на одном языке.

Если вы слышали, что MCP называют «USB-C для AI», это хорошая картинка. Дальше мы на ней и построим объяснение.

## Какую проблему решает MCP

Сам по себе AI-ассистент знает только то, чему его обучили, и то, что вы вставили в чат. Он не видит ваш календарь, трекер задач, документы или записи встреч, пока его кто-то к ним не подключит.

Раньше каждое подключение делали вручную. Если ассистентов несколько, а приложений много, для каждой пары нужен свой коннектор. Anthropic описывала это как проблему «N×M»: много ассистентов умножить на много инструментов даёт огромное число отдельных интеграций.

MCP заменяет это одним стандартом. Приложение делает одно MCP-подключение, и любой ассистент с поддержкой MCP может им пользоваться.

## Аналогия с USB-C

Вспомните зарядки до USB-C: для каждого устройства свой кабель. USB-C дал всем один разъём, который подходит к разным устройствам.

MCP делает то же самое для AI:

- **Ассистент** — это ноутбук с портом USB-C.
- **Приложение или источник данных** (встречи, файлы, база данных) — это устройство, которое вы подключаете.
- **MCP** — стандартный разъём между ними.

## Как это работает: три роли

В MCP три части, и достаточно запомнить, чем каждая занимается:

1. **Хост.** AI-приложение, которым вы пользуетесь, например AI-ассистент или инструмент для программирования.
2. **Клиент.** Небольшой компонент внутри хоста, который поддерживает соединение с одним сервером.
3. **Сервер.** Программа, которая отдаёт ассистенту инструмент или данные. Она может работать на вашем компьютере или удалённо.

Они обмениваются сообщениями в стандартном формате (JSON-RPC 2.0), поэтому вдаваться в детали пользователю не нужно.

## Что может предложить MCP-сервер

Если упростить, сервер может дать ассистенту:

- **Инструменты:** действия, которые он может выполнить, например поиск, создание задачи или расчёт.
- **Ресурсы:** содержимое, которое он может прочитать, например документы или FAQ.
- **Подсказки (prompts):** готовые инструкции для типовых задач.

## Простой пример

Допустим, вы хотите, чтобы ассистент помог с проектом. С MCP это выглядит так:

1. Вы задаёте вопрос в своём ассистенте.
2. Ассистент видит, какие MCP-серверы подключены и что умеет каждый.
3. Он обращается к нужному серверу за информацией или действием.
4. Сервер возвращает результат, и ассистент использует его в ответе.

Вы остаётесь в одном месте, а ассистент сам обращается к приложениям.

## Кто использует MCP

Anthropic представила MCP 25 ноября 2024 года. OpenAI приняла его в марте 2025 года, Google DeepMind тоже его поддерживает. В декабре 2025 года Anthropic передала MCP в Agentic AI Foundation, фонд при Linux Foundation, то есть стандартом больше не управляет одна компания.

## MCP и Dicta

Dicta поддерживает MCP: согласно [странице для разработчиков](/ru/developers/), Dicta можно подключить к AI-ассистентам с поддержкой MCP и работать со своими встречами из привычного ассистента.

Это важно, потому что во встречах много решений, которые иначе остаются в записях и заметках. Dicta уже записывает встречи, расшифровывает их по спикерам на узбекском, русском и английском и делает [AI-резюме](/ru/features/ai-summary/) с решениями и [задачами](/ru/features/tasks-integrations/). MCP — мост, который позволяет ассистенту обратиться к этим знаниям, а не копировать их вручную.

## Безопасен ли MCP

MCP мощный, потому что позволяет ассистенту читать данные и выполнять действия. Именно поэтому нужна осторожность:

- **Подключайте только серверы, которым доверяете.** Вредоносный сервер может попытаться ввести ассистента в заблуждение (это разновидность prompt injection).
- **Проверяйте выдаваемые права.** Разрешайте только те данные и действия, которые нужны для задачи.
- **Просматривайте действия до выполнения,** особенно если что-то отправляется, изменяется или удаляется.
- **Обновляйте программы.** В инструментах MCP находили и исправляли уязвимости, а профильные ведомства предупреждали, что распространение MCP опережает развитие его безопасности.

Сам протокол уже включает требования безопасности, например авторизацию на основе OAuth, но безопасное использование зависит от того, что вы подключаете.

## Частые вопросы

**Как расшифровывается MCP?**\
Model Context Protocol.

**MCP — это AI-модель?**\
Нет. Это стандартный способ подключения AI-ассистентов к приложениям и данным, а не модель.

**Нужно ли быть разработчиком, чтобы пользоваться?**\
Не обязательно. MCP-серверы создают разработчики, а вы пользуетесь ими через ассистента с поддержкой MCP.

**MCP только для Claude?**\
Нет. Он появился в Anthropic, но это открытый стандарт, которым пользуются и другие компании.

**Поддерживает ли Dicta MCP?**\
Да, согласно странице Dicta для разработчиков.
